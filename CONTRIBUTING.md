# Contributing

Thanks for your interest in contributing! This is primarily a solo learning project, but useful PRs are welcome.

## Ground rules

1. **Open an issue first** for anything non-trivial so we can align on approach before you spend time.
2. **Keep PRs small and focused** — one feature or fix per PR.
3. **Match existing style.** This project values readability; code is written to be learned from.
4. **No generated artifacts** in commits (build output, IDE files, OS junk).

## Commit messages

Use imperative mood and a short subject line, e.g.:

```
Add fixed timestep loop to game loop
```

## Testing

Run any existing build/tests before submitting. As the project grows, CI and test expectations will be documented here.

## Licensing

By contributing, you agree that your contributions will be licensed under the project's license (see `LICENSE` if present; otherwise the maintainer's choice at merge time).
